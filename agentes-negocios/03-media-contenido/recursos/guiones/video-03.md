# Vídeo 3 — 5 prompts que me ahorran 5 horas a la semana
Duración objetivo: 9–11 min · Palabras clave: "prompts chatgpt" y "tutoriales ia"

## Gancho (0:00–0:20)
"Estos 5 prompts me ahorran unas 5 horas a la semana. Te los doy literales, para copiar y pegar, y te enseño a adaptarlos a tu trabajo."
(No es una promesa de resultados: se presenta como experiencia propia y estimada.)

## Prompt 1 — El resumidor de reuniones (0:20–2:20)
```
Actúa como secretario de actas. A partir de estas notas/transcripción, genera:
1) Resumen en 5 viñetas, 2) Decisiones tomadas, 3) Tareas con responsable y fecha en tabla,
4) Dudas pendientes. Si falta un responsable o fecha, escribe "POR DEFINIR". Notas: [...]
```
Demostración con una transcripción inventada.

## Prompt 2 — El "dime que no" educado (2:20–4:00)
```
Redacta un correo para rechazar [petición] de [persona/rol]. Tono: cordial y firme.
Ofrece una alternativa: [alternativa]. Máximo 120 palabras. Dame 2 versiones: formal y cercana.
```

## Prompt 3 — El informe semanal (4:00–6:00)
```
Con esta lista de lo que he hecho esta semana, escribe un informe para mi responsable con:
logros, bloqueos, próximos pasos. Estilo directo, viñetas, máximo 200 palabras. Lista: [...]
```

## Prompt 4 — El explicador (6:00–7:45)
```
Explícame [concepto/documento] como si tuviera 15 años y luego como experto, en 3 frases cada uno.
Después hazme 3 preguntas para comprobar que lo he entendido.
```

## Prompt 5 — El revisor crítico (7:45–9:30)
```
Actúa como un revisor exigente. Revisa este texto/propuesta y dame: 3 puntos débiles,
3 preguntas que me haría un cliente escéptico, y una versión mejorada. Texto: [...]
```

## Cierre (9:30–10:00)
"Estos 5 prompts y 45 más, organizados por tarea, estarán en un pack muy pronto. Si te apuntas a la newsletter (primer enlace), te aviso el primero y te llevas 10 gratis ya."
